# gas/ — ซอร์ส Google Apps Script (โปรเจกต์ PT Station)

วางลงที่ script.google.com (ไม่ได้รันบน GitHub) — โปรเจกต์เดียว Web App ลิงก์เดียว

| ไฟล์ | ใน Apps Script | หมายเหตุ |
|---|---|---|
| `Code.gs` | Code.gs (วางทับ) | V30: ส่งคำขอศูนย์ยืมไป LoanCenter.gs · ฝั่ง GAS เขียนข้อมูลครุภัณฑ์ไม่ได้ (ดูอย่างเดียว) · ป้าย QR เก่าพาไปหน้าเว็บ GitHub |
| `LoanCenter.gs` | **ไฟล์ใหม่** ชื่อ LoanCenter (สคริปต์) | API ศูนย์ยืม-คืน + `lcAdminOverview()` |
| `index.html` | index (HTML) วางทับ | ศูนย์ควบคุมอุปกรณ์ = ดูอย่างเดียว · หน้าคำขอนัดหมาย: ปุ่ม "สร้างนัดหมายจากคำขอ" |
| `Linebooking.gs` | ไม่เปลี่ยน | |
| `appsscript.json` | ไม่เปลี่ยน | สิทธิ์เดิมครอบคลุมแล้ว |

## ขั้นตอน (ทำครั้งเดียว)
1. วาง `Code.gs`, `index.html` ทับของเดิม และสร้างไฟล์ `LoanCenter.gs` (ไฟล์สคริปต์ใหม่) แล้ววางเนื้อหา
2. ใน `LoanCenter.gs` ฟังก์ชัน `lcSetConfig()` ใส่ `STAFF_PIN` และ `ADMIN_PIN` (≥ 6 ตัว ต้องไม่ซ้ำกัน) → เลือก `lcSetConfig` → Run → **ลบ PIN ออกจากโค้ดทันที**
   (ตรวจ `FRONTEND_URL` ว่าตรงกับลิงก์ GitHub Pages ของ `/loan/` ของคุณ)
3. Run `lcSetupLoanCenter` (สร้าง/เติมคอลัมน์ชีตครุภัณฑ์ — ข้อมูลเดิมไม่หาย)
4. Deploy → Manage deployments → ✏️ → New version → Deploy (ลิงก์ `/exec` เดิม ไม่ต้องแก้หน้าเว็บ)
5. ถ้าเคยพิมพ์ป้าย QR ไปแล้ว: ป้ายเดิมยังใช้ได้ (พาไปหน้าครุภัณฑ์ → ปุ่มเปิดศูนย์ยืม-คืน) / ต้องการให้ป้ายชี้ GitHub โดยตรง ให้เปิดศูนย์ยืม-คืน → พิมพ์ QR ใหม่ (ผู้ดูแลมีปุ่มสร้าง QR ใหม่ทั้งหมด หรือรัน `lcRegenerateAllQr`)
6. ทดสอบ: เปิด `/loan/` ด้วย PIN เจ้าหน้าที่ → เพิ่มครุภัณฑ์ → ให้ยืม → ดูที่ลิงก์ Apps Script เมนู "ศูนย์ควบคุมอุปกรณ์" ต้องเห็นรายการยืม
