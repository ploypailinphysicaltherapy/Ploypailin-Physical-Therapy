ของใหม่ในหน้า /loan/staff.html
  1) ปุ่มค้นหาทั่วระบบ (กด / หรือ Ctrl+K) — ครุภัณฑ์ + ผู้ยืม/เบอร์โทรของรายการที่ยืมอยู่
  2) กระดิ่งแจ้งเตือน — เกินกำหนด / ใกล้ครบกำหนด / ถึงกำหนดตรวจสภาพ (ตัวเลขแดงเมื่อมีเกินกำหนด)
  3) เมนู "รายงาน / Excel" — สรุปตามช่วงวันที่ (เดือนนี้/30 วัน/ปีงบประมาณ/1 ปี), กราฟแท่ง, ตารางรายการ,
     พิมพ์รายงาน, ส่งออก .xlsx 3 แผ่น (สรุป/รายการยืม-คืน/ครุภัณฑ์) — ถ้าโหลดตัวสร้าง Excel ไม่ได้จะให้ .csv แทน
  4) เมนู "ปฏิทินการยืม" — heat map ย้อนหลัง 12 เดือน แตะวันเพื่อดูรายการ สลับดูวันที่ยืม/วันที่คืน
  5) ปุ่มพิมพ์ "ใบยืม-คืน" (A4 หน้าเดียว มีส่วนรับคืน + ช่องลงนามเว้นไว้) — ในรายการที่ยืมอยู่และในหน้ารายงาน
  * ส่วนรายงาน/ปฏิทิน/ใบพิมพ์อยู่ในไฟล์ reports.js ที่โหลดเมื่อเข้าหน้านั้นเท่านั้น หน้าแรกไม่หนักขึ้น
  * ไม่เปลี่ยนโครงสร้างชีต ไม่เพิ่มคอลัมน์ ไม่เปลี่ยนระบบสิทธิ์ (ใช้ PIN แอดมินเดิม)
