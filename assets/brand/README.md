## กติกาการใช้
- ใส่ `width` / `height` ในแท็ก `<img>` เสมอ (กันหน้ากระตุก) และ `loading="lazy"` ยกเว้นรูปแรกที่เห็นทันที
- เป็นภาพตกแต่ง ใช้ `alt=""` ยกเว้นรูปที่สื่อความหมายเอง
- ไอคอนใช้ที่ขนาดตั้งแต่ ~56px ขึ้นไป (ต่ำกว่านี้ให้ใช้ไอคอน SVG เส้นของหน้า เพราะภาพวาดสีจะเบลอ)
- ภาพต้นฉบับเป็น raster ไม่ควรขยายเกินขนาดจริง (มาสคอตสูงสุด ~676px)
